# Weather Report App (React + axios + OpenWeatherMap)

## Run it

```bash
npm install
npm start
```

Opens at http://localhost:3000. Restart `npm start` after editing `.env`.

## API key

The key is read from `.env` as `REACT_APP_WEATHER_API_KEY`. `.env` is in `.gitignore`,
so it will not be pushed to GitHub. See `.env.example` for the format.
New OpenWeatherMap keys can take up to a couple of hours to activate.
